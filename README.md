# Fléchettes à la voix

Appli web pour annoncer ses fléchettes à la voix (en français) et compter les points.

Ouvrir sur le téléphone : https://rafalafel13.github.io/fl-chette/

## Appli complète (mobile)

L'appli de jeux (301/501, Cricket, La Montante, statistiques, saisie vocale ou manuelle) est dans `app/` : https://rafalafel13.github.io/fl-chette/app/

Sur le téléphone, ouvre ce lien dans Chrome puis « Ajouter à l'écran d'accueil ».
